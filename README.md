# Harness-Aware Distillation for Small Language Model Agents

Project page: https://moon4sake.github.io/harness-aware-distillation/

The code, the harness, and the training scripts will be released in this repository.

## Project page

The page is a single static file, `index.html`, served by GitHub Pages.

1. The page needs two files: `index.html` and `static/images/fig1.svg`.
   Every other figure (the TL;DR scatter, the method figure, the analysis
   drawings) is embedded inline in `index.html` as SVG with text outlined,
   so no fonts or extra assets are required. `static/images/fig3.svg` is
   kept only as the source of the method figure.
2. Fill in the arXiv link in `index.html` and in the BibTeX below.
3. In the repository settings, open Pages and serve from the `main` branch, root folder.
